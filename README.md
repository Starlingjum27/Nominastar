# NOMINA STAR
Sistema de nómina web para Venezuela (Python + Streamlit + SQLite)

## Archivos
- app.py  -> El sistema completo
- requirements.txt -> Dependencias

## Despliegue gratis en Streamlit Cloud
1. Sube estos archivos a un repositorio de GitHub
2. Entra a https://share.streamlit.io con tu cuenta GitHub
3. New app -> selecciona el repositorio -> archivo app.py -> Deploy
4. En Settings puedes cambiar el subdominio a: nominastar.streamlit.app
